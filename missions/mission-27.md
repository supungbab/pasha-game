## 게임 설명

**10개의 도형을 연속으로 목표 각도에 맞추는 빠른 퍼즐 게임입니다.** 하단의 좌/우 버튼을 탭하면 도형이 60도씩 회전하며, 목표 각도와 일치하면 자동으로 다음 도형으로 넘어갑니다. 적은 탭 횟수로 빠르게 맞출수록 고득점합니다.

## 게임 규칙

1. 10종의 다른 도형이 셔플되어 순서대로 등장
2. 가능한 각도: 0°, 60°, 120°, 180°, 240°, 300° (6개 위치)
3. 목표 각도가 중앙 원 테두리에 금색 마커로 표시
4. **왼쪽 버튼** → 반시계 방향 60도 회전
5. **오른쪽 버튼** → 시계 방향 60도 회전
6. 목표 각도와 일치하면 **자동 성공 판정** → 다음 도형으로 전환
7. 10라운드 완료 또는 제한시간 종료 시 게임 끝

## 점수 시스템

### 기본 점수 (탭 횟수 기반)

| 탭 횟수 | 점수 | 표시 |
|---------|------|------|
| 1회 (최단) | 20점 | PERFECT! |
| 2회 | 15점 | GREAT! |
| 3회 | 10점 | GOOD |
| 4회+ | 5점 | OK |

### 콤보 (연속 PERFECT)

| 연속 PERFECT | 배율 |
|-------------|------|
| 0~1회 | x1.0 |
| 2회 | x1.3 |
| 3회+ | x1.5 |

### 점수 공식
```typescript
// 탭 횟수에 따른 기본 점수
if (tapCount === 1) points = 20;      // PERFECT
else if (tapCount === 2) points = 15;  // GREAT
else if (tapCount === 3) points = 10;  // GOOD
else points = 5;                       // OK

// 콤보 배율 적용
if (consecutivePerfects >= 3) multiplier = 1.5;
else if (consecutivePerfects >= 2) multiplier = 1.3;
else multiplier = 1.0;

finalPoints = Math.round(points * multiplier);
```

### 대기 블록 표시
- 중앙 원 **양쪽**에 다음 도형들이 작은 블록으로 대기
- 왼쪽: 완료한 도형들 (흐리게)
- 오른쪽: 앞으로 할 도형들
- 클리어 시 다음 블록이 중앙으로 전환
