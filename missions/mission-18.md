## 게임 설명

위아래로 왕복하는 막대를 화면의 정지선(빨간 점선)에 정확히 맞춰 탭하는 타이밍 게임입니다. 막대가 정지선에 가까울수록 높은 점수를 획득합니다. 리듬감을 익히면 연속 PERFECT가 가능합니다.

---

## 시작 전 지시문

```
정지선에 맞추세요! ⚡
```

**지시문 이모지**: ⚡ (번개)

---

## 게임 규칙

1. 화면 중앙에 세로 트랙이 표시되고, 막대가 위아래로 왕복함
2. 화면을 탭하면 막대가 그 위치에서 멈춤
3. 막대가 정지선(빨간 점선)에 가까울수록 높은 점수
   - **PERFECT**: 정지선 ±8~28px 이내 → 20점
   - **GOOD**: ±16~50px 이내 → 12점
   - **OK**: ±26~70px 이내 → 6점
   - **MISS**: 범위 초과 → 0점
4. 판정 후 막대가 자동으로 리셋되어 다음 라운드 시작
5. 제한시간 15초 동안 최대한 많이 시도

## 점수 시스템

### 점수 계산 방식
- **타입**: 정확도 기반
- **판정별 점수**:
  - PERFECT: 20점
  - GOOD: 12점
  - OK: 6점
  - MISS: 0점

### 점수 공식
```
score = Σ(각 라운드 점수)
목표 점수 = 60점 (PERFECT 3회 또는 GOOD 5회)
```

### 예시
| 시도 횟수 | PERFECT | GOOD | OK | 최종 점수 |
|----------|---------|------|----|----------|
| 6회 | 2 | 2 | 2 | 40+24+12=76 ✓ |
| 8회 | 1 | 4 | 3 | 20+48+18=86 ✓ |
| 10회 | 0 | 5 | 5 | 0+60+30=90 ✓ |

### 난이도별 목표 점수

| 난이도 | 목표 점수 | 배율 |
|--------|----------|------|
| Lv.1 | 60점 | ×1.0 |
| Lv.2 | 72점 | ×1.2 |
| Lv.3 | 90점 | ×1.5 |

## 구현 로직

### 게임 상태
```typescript
let barY = TRACK_TOP + BAR_H / 2  // 막대 중심 Y
let barDir = 1                      // 1=아래, -1=위
let frozen = false                  // 막대 고정 여부
let targetY = 0                     // 정지선 Y 위치
let barResultColor = '#FF9800'      // 판정 후 색상
```

### 막대 이동
```typescript
function update() {
  if (frozen) return
  barY += barDir * speed
  if (barY >= TRACK_BOTTOM - BAR_H / 2) {
    barY = TRACK_BOTTOM - BAR_H / 2
    barDir = -1
  } else if (barY <= TRACK_TOP + BAR_H / 2) {
    barY = TRACK_TOP + BAR_H / 2
    barDir = 1
  }
}
```

### 탭 판정
```typescript
function handleTouch() {
  frozen = true
  const dist = Math.abs(barY - targetY)
  if (dist <= perfect) score += 20       // PERFECT
  else if (dist <= good) score += 12     // GOOD
  else if (dist <= ok) score += 6        // OK
  else score += 0                        // MISS

  // 650ms 후 다음 라운드
  setTimeout(() => startNewRound(), 650)
}
```

### 시각적 피드백
- 막대가 PERFECT 구역에 가까워지면 황금색 글로우 효과
- 판정 후 막대 색상이 판정 결과 색으로 변경
- PERFECT/GOOD/OK/MISS 텍스트가 페이드아웃으로 표시
