## 게임 설명

게이지 바에 초록색 "목표 구간"이 표시됩니다. 화면을 터치하면 게이지가 채워지기 시작하고, 게이지가 목표 구간에 도달했을 때 손을 떼면 PERFECT! 10초 동안 여러 라운드를 반복합니다.

## 게임 규칙

1. 화면 터치 → 게이지가 채워지기 시작
2. 게이지가 초록색 목표 구간에 도달했을 때 손을 떼기
3. 판정:
   - **PERFECT** (목표 중심 ±30%): 10점
   - **GOOD** (목표 구간 내): 7점
   - **MISS** (구간 밖): 0점
4. Lv.1-3: 게이지가 한 방향으로 채워짐
5. Lv.4-6: 게이지가 좌우로 왕복 진동 (sin파)
6. 게이지가 끝까지 차면 자동 MISS 처리

---

## 점수 시스템

### 점수 계산 방식
- **타입**: 정확도 기반
- **PERFECT**: 10점
- **GOOD**: 7점
- **MISS**: 0점

### 결과 데이터
- `score`: 총 점수
- `successCount`: PERFECT + GOOD 횟수
- `attempts`: 총 시도 횟수
- `accuracy`: 정확도 (successCount / attempts × 100)

### 색상 팔레트

### 시각 요소
- **수평 게이지 바**: 구간 표시 + 현재 위치 삼각형 인디케이터
- **원형 게이지**: 보조 시각화, 파이 차트 스타일
- **중앙 이모지**: 상태별 (👆 대기, 💪 홀드, ✋ 릴리즈)
